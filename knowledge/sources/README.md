# knowledge/sources/ — 知识库文献原文

此目录存放知识库的文献全文（书籍/论文转写文本），**因版权原因不纳入版本控制**。

## 放什么

运动科学相关书籍与论文的全文文本（.md）或 PDF（走 `scripts/ingest_pdfs.py`）。当前知识库构成（~11000 切片）：

- Springer 运动科学专著 4 部（运动生理、运动肺病学、内分泌与运动、细胞代谢与运动）
- 公开论文 8 篇（蛋白质补充 meta 分析、REDs 共识、自然健美备赛、肌酸立场声明等，均为可公开获取的开放获取文献）

## 文本文件格式

markdown，`[12]` 形式的页码标记行用于页级溯源（正则见 `app/services/rag.py`）。入库前在 `scripts/ingest_pdfs.py` 的 REGISTRY 登记真实书目信息（title / authors / year / DOI）——**引用可溯源的前提是元数据真实**。

## 为什么不公开

书籍转写文本受版权保护。本项目只做个人学习用途；他人复现请自行准备正版文献文本。
